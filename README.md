# KULHAD TALES — POS / Billing (Print Fixed)

This version keeps the existing KULHAD TALES website and adds a simple demo POS.

## Important
- Selecting a menu item only adds it to the cart. It NEVER prints anything.
- Payment is demo mode; no real money is charged.
- The bill appears on screen after clicking Pay & Generate Bill.
- Print / Save PDF opens a separate small receipt window, so the full website is not printed and blank/multiple pages are avoided.
- If the browser blocks the receipt window, allow pop-ups for the site and click Print / Save PDF again.

## GitHub
Replace only `index.html`, `styles.css`, and `script.js` in the existing `kulhad-tales` repository. Keep all existing image files.
