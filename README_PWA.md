# KULHAD TALES — PWA

This is the professional KULHAD TALES site converted into an installable Progressive Web App (PWA).

## GitHub Pages
Upload/replace the project files in the existing `kulhad-tales` repository. Keep all images in the repository root.

New PWA files:
- `manifest.webmanifest`
- `sw.js`

Updated:
- `index.html`

After GitHub Pages deploys, open the site on a supported phone/browser and choose **Add to Home Screen** / **Install App**.

The service worker caches the app shell and supplied images for faster repeat loading and basic offline access.
